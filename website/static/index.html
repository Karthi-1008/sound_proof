ABOUT SOUNDPROOF PRO

SoundProof Pro v3.2 is a state-of-the-art offline speaker verification platform engineered for audio professionals, forensic investigators, journalists, and researchers.

Powered by SpeechBrain's ECAPA-TDNN (Emphasized Channel Attention, Propagation and Aggregation in Time-Delay Neural Networks) pre-trained on VoxCeleb1+2, achieving ~0.8% Equal Error Rate (EER).

Built with Python 3, PyTorch, Torchaudio, FastAPI, and Vanilla JS • SoundProof v3.2.0 Pro Studio
